# ============================================
# 📝 动态说说模板（Dynamic Template）
# 作用：一键新增一条「动态/说说」到动态页
#
# ✅ 最推荐用法（自动插入，无需手动编辑）：
#   终端执行：
#   npm run dynamic -- "今天写了个新功能，很开心！🚀"
#
#   带日期：
#   npm run dynamic -- "今天写了个新功能" 2026-08-15
#
#   多行内容（用引号包裹，\n 换行）：
#   npm run dynamic -- "第一行\n第二行"
#
# 脚本会自动把说说插入到 source/_data/dynamics.yml 最顶部
# （保持日期倒序），保存后 push 到远端即触发构建更新。
#
# ✅ 也可以直接对 AI 说：「发条动态：xxx」，AI 会自动调用 add_dynamic 技能插入。
# ============================================
